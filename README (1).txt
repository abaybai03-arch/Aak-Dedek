WEB ULANG TAHUN - MUSIK FINAL

Versi ini menggunakan musik yang DITANAM LANGSUNG ke dalam index.html (base64).
Jadi index.html tidak bergantung pada file musik terpisah dan lebih aman saat dibuka dari file lokal/content:// maupun GitHub Pages.

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html.
3. Klik "Buka surat kecil dari Aak".
4. Musik mulai setelah klik tersebut.

Catatan: browser memang melarang autoplay tanpa interaksi pengguna. Karena itu musik diputar dari aksi klik tombol.
